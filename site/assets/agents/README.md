# Agent identifiers

These locally served assets identify the Agent examples in the homepage and its
How it works diagram. They are not a compatibility matrix or an endorsement.

Claude Code, Codex, OpenCode and Pi SVGs are copied without modification from
[Lobe Icons](https://github.com/lobehub/lobe-icons), commit
`7d7d0379f18b114a4009dc5cb85a7c375284f31b`, under MIT (see
[LICENSE-lobe-icons.txt](LICENSE-lobe-icons.txt), also included in the site build):

- `claude-code.svg`: `packages/static-svg/icons/claudecode-color.svg`
- `codex.svg`: `packages/static-svg/icons/codex-color.svg`
- `opencode.svg`: `packages/static-svg/icons/opencode.svg`
- `pi.svg`: `packages/static-svg/icons/pi.svg`

`fx.png` is the unmodified official favicon from <https://fx.sh/favicon.png>.
It identifies [Vercel Labs fx](https://github.com/vercel-labs/fx), whose project is
Apache-2.0 licensed. The icon retains its original background and aspect ratio.
Brand names and marks belong to their respective owners.

The static build copies these files as-is. No browser requests go to a third-party
CDN. Keep upstream notices when updating these resources.
